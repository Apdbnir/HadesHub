# Лабораторная работа №6: Мониторинг Bluetooth устройств

## Описание задачи
Реализовать мониторинг устройств, подключаемых через интерфейс Bluetooth. Подключиться к устройству и выполнить задание: передать файл с ноутбука на Bluetooth-устройство (например, умную колонку, наушники) и реализовать механизм автоматического воспроизведения после передачи.

## Техническое задание
1. Мониторинг доступных Bluetooth-устройств
2. Подключение к Bluetooth-устройствам
3. Передача файлов на Bluetooth-устройства (например, аудио-файлы на колонку или наушники)
4. Автоматическое воспроизведение переданных аудио-файлов на устройстве

## Архитектура решения

### Electron-приложение (lab6/ui/)
- **main.js**: Основной процесс Electron, взаимодействие с Bluetooth API
- **renderer.js**: Визуальный интерфейс, обработка пользовательских действий
- **preload.js**: Обеспечивает безопасный доступ к API Electron из renderer
- **index.html**: HTML-разметка пользовательского интерфейса
- **style.css**: Стили интерфейса
- **translate.js**: Механизм локализации (русский/английский)

### C++ реализация (lab6/main.cpp)
- Класс `BluetoothMonitor`: основной класс для мониторинга Bluetooth-устройств
- Класс `BluetoothDevice`: представление Bluetooth-устройства
- Функции обнаружения, подключения и передачи файлов
- Поддержка Windows и Linux через условную компиляцию

## Используемые технологии
- **Electron.js**: для создания кроссплатформенного десктопного приложения
- **@abandonware/noble**: библиотека для работы с Bluetooth LE
- **Windows Bluetooth API**: для работы с Bluetooth на Windows
- **BlueZ**: для работы с Bluetooth на Linux (через системные вызовы)

## Функциональность

### Мониторинг устройств
- Сканирование доступных Bluetooth-устройств
- Отображение информации об устройствах (название, ID, уровень сигнала)
- Обновление списка сопряженных устройств

### Подключение к устройствам
- Возможность подключения к обнаруженным и сопряженным устройствам
- Индикация статуса подключения

### Передача файлов
- Выбор файла для передачи
- Отслеживание прогресса передачи
- Поддержка передачи файлов на Bluetooth-устройства

### Автоматическое воспроизведение
- После успешной передачи аудио-файла на совместимое устройство (например, колонку или наушники), запускается автоматическое воспроизведение
- Поддержка основных аудио-форматов

## Запуск приложения
```bash
# Установка зависимостей
cd lab6/ui
npm install

# Запуск приложения
npm start
```

## Особенности реализации
- Приложение поддерживает переключение языка интерфейса (русский/английский)
- Поддержка как новых, так и устаревших Bluetooth-устройств
- Обработка ошибок и индикация статуса операций
- Адаптивный дизайн интерфейса

## Технические детали
Для передачи файлов через Bluetooth в приложении используется симуляция протоколов OBEX и A2DP, а для автоматического воспроизведения используется AVRCP (Audio/Video Remote Control Profile), что соответствует стандартам Bluetooth для аудио-устройств.
